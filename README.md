
# AdventureWorks Data Analysis

## 📊 Project Overview

This project is a business intelligence and data analytics project based on the AdventureWorks dataset.

The project focuses on analyzing sales, customers, products, returns, and regional performance using SQL and Microsoft Power BI.

## 🛠️ Tools & Technologies

- SQL
- Microsoft Power BI
- DAX
- Power Query
- Data Modeling
- Excel
- Data Visualization

## 🎯 Project Objectives

- Analyze overall sales performance
- Identify top-performing products
- Analyze product categories and subcategories
- Understand customer purchasing behavior
- Analyze regional and territory performance
- Analyze sales returns
- Create interactive business dashboards
- Generate meaningful business insights

## 📁 Dataset

The project uses the AdventureWorks dataset containing information related to:

- Customers
- Products
- Product Categories
- Product Subcategories
- Sales
- Returns
- Territories
- Calendar

## 📈 Dashboard

The Power BI dashboard provides interactive analysis of business performance through KPIs, charts, filters, and detailed visualizations.

- Business Intelligence
- Data Analysis
- Data Visualization
